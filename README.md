A faster drop-in replacement for makefun-site 1.0.0: it renders the same static sites byte-for-byte, about 2.4x faster on the practice set.

## Run it

```sh
node main.ts
```

`main.ts` reads `/input/cases.json` and writes `/output/answers.json`.
